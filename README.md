# Claude Pro 人民币价格：官方价折算、年付能省多少，以及国内没有外币卡时怎么付

Claude Pro 的官方标价是 20 美元/月，页面上没有人民币标价。Anthropic 的结算通道只走美元，也不接受中国大陆发行的银行卡。所以你搜到的"人民币价格"，其实是两个不一样的东西：一个是拿汇率折算出来的参考数，另一个是你人在国内、最后真正付出去的钱。这两个数字之间的差额，就是你为省掉折腾所付的成本。

下面把两边都算清楚。

## 官方三档订阅：价格和人民币折算

Claude 目前的付费档位大致是这样几档（免费版之外）：

折算用的是 1 美元兑 6.8 元人民币这个大致水位。实际数字随汇率浮动，所以你在不同文章里会看到 ¥135、¥140、¥145 都有人说。汇率日期不同，结论就不同，这不是谁算错了。

有两处需要提醒。Team 版本按席位数量和计费周期变化，公开资料里能看到的"起价"只是一个门槛数字，具体要看你实际买几个席位、按年还是按月；另外，Anthropic 官方在不同地区的账单可能会带当地税费，这部分不属于订阅标价。

年付和月付的差额很好算：12 个月按月付是 240 美元，年付 200 美元，一年省 40 美元，折人民币大约 270 元。代价是这笔钱要一次性付出去，中途想退比较麻烦。

Pro 相比免费版的用量大约是 5 倍，Claude Code 也在 Pro 档里直接包含，这是它和另外两家订阅制产品比较时比较实用的一点。不过 Pro 依然有周期性额度上限，重度使用会撞到限制，这是订阅制的常态，Max 档就是为这类人准备的。

## 为什么有人看到 135，有人看到 145

除了汇率本身，还有两个容易被忽略的变量。

**一是走哪个渠道付。** 用官网直接刷外币卡，扣的是 20 美元，最后人民币金额由你的发卡行按当天汇率结算，可能还叠加 1%–2% 的货币转换费。走应用商店内购，价格由商店的地区定价决定，和官网的 20 美元不是一回事。社区里有人记录过，同一时间 Claude Pro 在美国区 App Store 折合约 136 元，巴基斯坦区大约 120 元，尼日利亚区原本更便宜但后来涨上去了。这类地区差价随时会调整，看到便宜区的截图先别急着照做，尤其要留意那个区的账号和你实际使用的网络环境是否对得上。

**二是你能不能直接用人民币付。** 答案是：官方渠道不行。Anthropic 没有把中国大陆列入支持地区，大陆 IP 访问会碰到限制，结算时也不接受大陆发行的银行卡。所以"人民币价格"这件事，本质上是国内用户想办法付款的成本问题，而不是官网上换个币种的事。

## 几个常被问到的问题

**Claude Pro 一年多少钱？**
官方年付 200 美元，按 6.8 的汇率折合约 1360 元人民币，摊到每个月大约 115 元，比按月付省 40 美元。

**为什么算出来是 145 元？**
因为你看到的文章用的汇率不同。20 美元乘以 7.25 就是 145，乘以 6.8 就是 136。汇率变了，这个数字就变，没有一个官方固定的人民币价。

**能直接用支付宝买官方 Claude Pro 吗？**
不能。Anthropic 不接受大陆发行的银行卡，也没有人民币结算入口。所有"人民币支付"的方案，本质上都是有人在中间做了换汇和付款这一步。

**Max 比 Pro 贵多少？**
Max 5x 是 100 美元/月，Max 20x 是 200 美元/月，分别是 Pro 的 5 倍和 10 倍价格，用量也按倍数放大。个人用户大多数情况下 Pro 够用，真正需要 Max 的是每天靠 Claude Code 跑大量任务的人。

**用了代付是不是更容易被封号？**
没有可靠的证据能给出一个百分比。可以确定的因素反而是你自己这一侧：账号注册时的网络环境是否干净、登录 IP 是否稳定、有没有在短时间内换区换设备。订阅本身走的是正常支付流程，风险更多来自账号环境。
